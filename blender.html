Blender

Some basic informations, tips and tricks about Blender (tested on Blender 5.2.0 LTS)

How to create a human character using Skin modifier:

  1. Add a plane, select every vertex and press M to merge
  2. Add Mirror modifier (optional - merge distance to 0.1) (optional - enable clipping, but remember that it will be a problem with only one vertex in the middle)
  3. Add Skin modifier (optional - enable smooth shading)
  4. Add Subdivision Surface modifier (optional - viewport level to 2)
  5. Remember about x-ray mode (alt+z)
  6. Extrude to create! Start with hips, legs, feet, torso, shoulders, arms, neck, head.
  7. Remember to create a character in a T-pose. Character thumbs should go forward, not upwards
  8. Ctrl+A - scaling (separate axes also work - flatten ends of the feet for example)
  9. Root node needs to be on center! Hips for example. Select Pelvis vert and in modifier window click Mark Root.
  10. Remember that you can select two vertices and right click -> subdivide
  11. Remember that you can select vertex, ctrl+shift+b = divide one vert into two and move them apart. Bevel?
  12. Remember that you can use Ctrl+R to do loop cuts.

How correctly export a model from Blender to Unity:

  1. Remember to apply rotation and scale of the model. Set model pivot to world origin (zero point).
  2. In Blender export window set Apply Scalings to FBX All
  3. Set Forward to -Y Forward
  4. Set Up to Z Up
  5. In Unity asset import window set Bake Axis Conversion to true and then apply.

Other tips:

  • Merge two meshes into one: in object mode, select (soon to be) child mesh, select parent mesh, press Ctrl+J
  • Parent meshes: in object mode, select (soon to be) child mesh, select parent mesh, press Ctrl+P
  • Hide selected - H
  • Hide all but selected - Shift+H
  • Reveal all hidden - Alt+H
